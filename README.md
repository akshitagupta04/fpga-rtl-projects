# FPGA Prototyping and RTL Design Projects 
August 2022 – Present

<p align="justify">
Completed an 8-week online training on VLSI Design by Internshala Trainings in October 2022, during GATE preparation. Gained hands-on experience with Verilog HDL, basic RTL Design, and designed digital circuits using Xilinx Vivado 2018.1. 
</p>

<p align="justify">
In September 2025, I transitioned fully into practical digital hardware implementation through RTL Design, FPGA prototyping, and Hardware Design. Actively developing projects in VHDL, Verilog RTL-to-bitstream flow and FPGA prototyping , along with UART, SPI, I2C, AXI, JTAG on Cmod A7 (Xilinx Artix-7 35T) FPGA board using Xilinx Vivado 2024.1. 
</p>

In this repository, each directory is divided into three sub-directories — VHDL Projects and Verilog Projects. It is organized as follows:

- **Learning Lab:** Designed foundational syntax tests and basic projects with a few FPGA implementations from training, but programmed from scratch.
- **Skill Development:** Designing intermediate or advance level projects with FPGA implementations from scratch, tutorial, or training. 
- **Personal Projects:** Personal FPGA and RTL Design projects with FPGA implementation.
