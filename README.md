# FPGA and RTL Design Projects 
Hands-on FPGA and RTL design projects, including synthesis, simulation, implementation and bitstream generation using Verilog/VHDL in the Xilinx Vivado 2024.1. Currently enhancing skills using Cmod A7 FPGA Board (Xilinx Artix-7 35T). 

This repository is organized as follows: 

- **Learning Lab:** Basic, foundational syntax tests and hardware projects.
- **Skill Development:** Projects from training or coursework.
- **Projects** Personal FPGA and RTL Design hardware projects.
