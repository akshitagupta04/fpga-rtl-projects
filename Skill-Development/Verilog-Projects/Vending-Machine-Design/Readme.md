# Vending Machine Design

## Overview 
<p align="justify">
This project involves re-designing an FSM-based synthesizable vending machine design that automates the product sale at public places. This is designed with only one product. This can be extended to multiple products as well.  
</p>
<p align="justify">
This FSM model is implemented in Verilog. The user can enter three different currency notes and select the product. Based on the price of the product, the machine dispenses the product and gives the change. 
</p>
<p align="justify">
Confirmed zero design violations through the in-built RTL Linter in Xilinx Vivado 2024.1. Simulated and successfully verified the proper functioning of the vending machine design. 
</p>
