# Traffic Light Controller System (FSM-based)

## Overview 
<p align="justify">
This project involves re-designing an FSM-based traffic light controller system that is to be installed on the intersection of four ways at a junction. 

This FSM model is implemented using Verilog code. The directions are assumed as north, west, south, and east. Only one direction of traffic is allowed to move at a time. Red, yellow, and green signals control the flow of the traffic on all the four direction. 

Successfully verified the Verilog RTL Design of Traffic Light Controller through the in-built RTL Linter (under RTL Analysis) in Xilinx Vivado 2024.1, confirming zero design violations. Simulated and successfully verified the proper functioning of the traffic light controller system.
</p>
