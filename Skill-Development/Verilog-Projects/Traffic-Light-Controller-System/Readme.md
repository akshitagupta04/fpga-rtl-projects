# Traffic Light Controller System

## Overview 
<p align="justify">
This project involves re-designing an FSM-based synthesizable traffic light controller system that is to be installed on the intersection of four ways at a junction. 

This FSM model is implemented in Verilog. The directions are assumed as north, west, south, and east. Only one direction of traffic is allowed to move at a time. Red, yellow, and green signals control the flow of the traffic on all the four direction. 

Confirmed zero design violations through the in-built RTL Linter in Xilinx Vivado 2024.1. Simulated and successfully verified the proper functioning of the traffic light controller system.
</p>
