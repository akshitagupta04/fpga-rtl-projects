# D Flip-Flop

## Overview

Reprogrammed D Flip-Flop (without reset) in Verilog HDL in Xilinx Vivado 2024.1. Succesfully verified the Verilog RTL Design of D flip=flop through the in-built RTL Linter (under RTL Analysis) in Xilinx Vivado 2024.1, confirming zero design violations. Simulated through forcing clock on different duty cycles and periods of input value.
