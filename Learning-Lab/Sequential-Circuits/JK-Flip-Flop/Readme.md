# JK Flip-Flop

Reprogrammed JK Flip-Flop in Verilog HDL in Xilinx Vivado 2024.1. Succesfully verified the Verilog RTL Design of JK flip=flop through the in-built RTL Linter (under RTL Analysis) in Xilinx Vivado 2024.1, confirming zero design violations. Simulated through forcing clock on different duty cycles and periods of input values.
