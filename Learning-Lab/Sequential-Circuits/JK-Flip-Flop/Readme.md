# JK Flip-Flop

Reprogrammed JK Flip-Flop in Verilog HDL in Xilinx Vivado 2024.1. Succesfully verified through Linter (under RTL Analysis), an in-built feature in Xlinx Vivado 2024.1, to confirm if Verilog RTL Design have any violations or not.

Simulated through forcing clock on different duty cycles and periods of input values.
