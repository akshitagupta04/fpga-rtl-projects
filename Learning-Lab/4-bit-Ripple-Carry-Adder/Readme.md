# 4-bit Ripple Carry Adder

## Overview 
Programmed and simulated 4-bit ripple carry adder in Verilog using Xilinx Vivado 2018.1 during Intershala training course "VLSI Design" in 2022. 

Reprogrammed verilog code and coded testbench for simulation, constraint file for FPGA implementation, alomg with full RTL-to-bitstream workflow and programmed Cmod A7 (Xilinx Artix-7 35T) FPGA board using Xilinx 2024.1 in 2026. Also, generated synthesized schematic, utilization report (after synthesis), and timing & power reports (after implementation). 

Successfully verified through simulation and one test case through LED observation (output pins assigned to LED pins) on Cmod A7-35T via connecting inputs pins of FPGA board to jumper wires on breadboard where 3.3V = logic 1 and GND = logic 0.
