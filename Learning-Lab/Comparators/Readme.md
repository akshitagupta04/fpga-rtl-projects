# Comparators: 1-bit, 2-bit and 4-bit

## Overview 
Reprogrammed and simulated 1-bit and 2-bit (using two 1-bit comparators) comparator in Verilog through dataflow modelling in Xilinx Vivado 2024.1. 

Also, programmed 4-bit comparator using four 1-bit comparators in Verilog through dataflow modelling in Xilinx Vivado 2024.1. Simulated 4-bit comparator through 9 test cases in Xilinx Vivado 2024.1.
