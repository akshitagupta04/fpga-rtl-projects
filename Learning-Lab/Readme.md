# Learning Lab

Foundational syntax tests and basic projects with FPGA implementation. These Verilog codes (except the LED blink) were programmed during the Internshala Training course "VLSI Design" using Xilinx Vivado 2018.1 in 2022. 

In 2026, I reprogrammed, simulated, and tested FPGA implementation on a few of them on the Cmod A7-35T FPGA Board (xc7a35tcpg236-1) using Xilinx Vivado 2024.1.
