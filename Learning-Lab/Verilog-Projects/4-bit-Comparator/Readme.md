# 4-bit Comparator 

## Overview 
Programmed 4-bit comparator using four 1-bit comparators in Verilog through dataflow modelling in Xilinx Vivado 2024.1. Succesfully verified the Verilog RTL Design of 4-bit comparator through the in-built RTL Linter (under RTL Analysis) in Xilinx Vivado 2024.1, confirming zero design violations. Simulated 4-bit comparator through 9 test cases in Xilinx Vivado 2024.1.
